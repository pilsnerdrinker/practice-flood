# P5 フラッド練習

絶妖星乱舞 P5 のフラッド処理を練習するためのページです。

斜め4列の予兆を確認し、中央付近で待機して、1回目安置 → 1回目跡地 → 2回目跡地へ移動する流れを練習できます。

## 対応方式

- Poikos式

## できること

### 実践

3カウント後に、予兆4枚、待機1枚、発動4枚が自動で進みます。

- 予兆4枚：赤い予兆を確認
- 待機1枚：発動前の待機
- 発動4枚：水色の危険床を見て安置を選択
- 各発動後：正解位置を短く表示
- 9枚目後：3つの正解位置と移動順を3秒表示

一問ごとモードをONにすると、1問ごとに正解表示で停止します。OFFの場合は、正解表示後に次の問題へ自動で進みます。

### 位置確認

1問を9枚のスライドで確認できます。

- 右上の `＜ ＞`：同じ問題内でスライド移動
- マップ下の `前へ / 次へ`：端まで進むと前後の問題へ移動
- `正解を表示`：6〜8枚目はそのスライドの正解位置、9枚目は3つの正解位置と移動順を表示

## 処理ルール

予兆1・2回目の共通安置で1回目発動を回避します。

その後、1回目跡地かつ90度となりの安置で2回目発動を回避し、その90度となりの安置へ進んで（来た方向には戻らず）、3・4回目発動を回避します。

## 出題パターン

現在は以下の8ルートを出題します。

| ルート |
|---|
| B → C → D |
| B → A → D |
| D → A → B |
| D → C → B |
| A → D → C |
| C → B → A |
| C → D → A |
| A → B → C |

## 操作

- `スタート`：実践を開始
- `一時停止`：実践中に停止、再開
- `正解を表示`：現在の問題の正解を表示
- `もう一度`：同じ問題を最初からやり直し
- `前の問題`：前の出題へ移動
- `別の問題`：別の出題へ移動
- `一問ごと`：ONにすると1問ごとに停止
